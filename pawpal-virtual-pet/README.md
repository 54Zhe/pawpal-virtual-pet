# 🐾 小爪伙伴 · PawPal

一个**单文件、零依赖**的虚拟宠物养成小游戏。纯原生 HTML / CSS3 / Vanilla JS 实现，打开即玩，2 秒内加载。

🎮 **在线试玩**：https://pawpal-virtual-pet.app.workbuddy.host/

## ✨ 玩法特色

- 🥚 **五系宠物**：鸟🦅 / 犬🐺 / 猫🦁 / 兔🦄 / 龙🐉，开局自选或随机，蛋 → 幼崽 → 少年 → 成年 → 王者 五段进化
- 📊 **五项属性**：饱食 / 清洁 / 心情 / 精力 / 健康，随真实时间衰减，互相联动（又饿又脏会生病）
- 🎾 **陪玩小游戏**：10 秒疯狂点击挑战，按手速结算金币、经验、心情
- 👗 **装扮商店**：11 件饰品（帽子 / 眼镜 / 颈部三槽位），金币购买、自由穿卸
- 💬 **气泡对话**：宠物会根据状态说话——饿了喊饿、脏了喊痒、生病会撒娇，操作均有即时台词反应
- 😴 **睡觉系统**：夜间主题 + Zzz 动画，睡醒两套衰减曲线
- 💰 **金币经济**：陪玩 +3、训练 +5、成长 +15；喂食、零食、看病、买装扮都要花钱

## 🛠 技术要点

| 需求 | 实现 |
|---|---|
| 后台 tab 暂停 | `visibilitychange` 监听 + `animation-play-state` 暂停所有 CSS 动画 |
| 离线结算 | `localStorage` 存 `lastTick` 时间戳，回前台按**时间差补偿**结算衰减，不依赖后台定时器 |
| 存档 | 全部状态序列化进 `localStorage`，`beforeunload` 兜底 |
| 美术 | 纯 emoji + CSS（气泡、粒子特效、渐变舞台），零图片资源 |
| 依赖 | **零 CDN、零框架、零构建**，单 HTML 文件 |

## 🚀 本地运行

无需任何环境，直接用浏览器打开 `index.html` 即可。

## 📦 GitHub Pages 部署

推送到 GitHub 后：`Settings → Pages → Source` 选择 `main` 分支根目录，保存后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可游玩。
